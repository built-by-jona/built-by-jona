## Featured Projects

### 01 — Excel Price Calculator

A Python application that automates product pricing calculations using Microsoft Excel.

Instead of manually calculating selling prices, sales totals, and profit across multiple products, users can upload a structured Excel workbook and automatically generate a completed pricing report.

**Key features**

- Excel workbook processing
- Automated selling-price calculations
- Sales and profit calculations
- Input validation
- Downloadable Excel reports
- Streamlit web interface
- Automated testing

**Built with:** Python · Pandas · OpenPyXL · Streamlit · Pytest

### 02 — Excel Cleaner

A Python application that cleans and prepares messy Excel workbooks for analysis, reporting, and business use.

Users can upload an Excel workbook, select worksheets and cleaning operations, preview the results, and download a newly cleaned workbook without modifying the original file.

**Key features**

- Multi-sheet Excel workbook support
- Blank row and column removal
- Extra-space cleanup
- Duplicate removal
- Auto-fit column widths
- Frozen header rows
- Before-and-after data previews
- Cleaning summary
- Downloadable cleaned workbook
- Automated testing

**Built with:** Python · Pandas · OpenPyXL · Streamlit · Pytest
